# React presentation and native authority

The web interface is a presentation client. Native SQLite owns production text and drafts. The browser preview does not create a second journal. The first slice deliberately implements only text services and exposes accurate unavailable capabilities for everything else.

Production ships a classic local JS bundle, CSS and HTML instead of relying on remote pages, a localhost server or file-origin ES module loading. The bridge is attached only in the native host, accepts bundled main-frame file URLs, validates protocol envelopes and parameters, and never exposes SQL, credential material or paths.

The small text service is newly implemented against the predecessor's preservation/revision principles. It does not claim to port the complete predecessor schema or imply cross-version archive compatibility. Future migration requires explicit format adapters into a disposable new vault.

The initial UI uses system fonts and original CSS without proprietary template assets. Exact React and tool distributions are vendored only to allow an offline clean install in the restricted environment. The archives retain their upstream package licensing; do not publish this development scaffold before reviewing dependency notices and platform support.
